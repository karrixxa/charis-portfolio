# Setup Instructions

The main project documentation now lives in `README.md`.

## Quick Start

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## What To Edit

- `src/Home.js` for the landing page intro and current updates
- `src/About.js` for bio, research summary, and fun facts
- `src/Work.js` for experience and leadership
- `src/Projects.js` for project cards
- `src/Contact.js` for links and resume download
- `public/copy.JPG` for the profile image
- `public/CharisXiongResume.pdf` for the resume

## Notes

- The contact form is UI-only until a real email or form endpoint is connected.
- `.env` and `.DS_Store` should not be committed.
- See `README.md` for fuller setup, structure, customization, and deployment details.
