# charis.xiong — portfolio

Built with React. Has an animated scatter plot background, a terminal-style "what i'm up to" section, and hand-drawn SVG cats walking across the navbar because why not.

## setup

```bash
npm install
npm start
```

## adding things

- **photo** → `/public/copy.JPG`
- **resume** → `/public/CharisXiongResume.pdf`
- **colors** → `App.css` under `:root`
- **content** → data arrays at the top of each page file
